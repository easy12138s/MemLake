## 关键设计决策记录

| 决策 | 取舍 |
|------|------|
| AGE 承载图而非独立图数据库 | PostgreSQL 单实例混合存储：节点表（pgvector + tsvector + JSONB）与 AGE 图事务内共写，节点与边一致性由数据库保证，免除多库同步与运维面扩大 |
| 认证每请求实时校验、不设缓存 | Key 吊销/轮换即时生效优先于吞吐（bcrypt 校验约 200-300ms CPU）；单实例吞吐上限由此约束，高吞吐需求出现时再评估带 TTL 的缓存 |
| 写操作全走审批暂存表 | 未审批内容不进检索、不进图谱；审批通过事务共写。自动审批 + 宽松模式为信任分级提供旁路 |
| 冲突检测四层门禁 | L0 硬判定（关键标识字段精确匹配）→ L1 候选域（项目/system + 类型）→ L2 关键属性 → L3 语义阈值 0.85；阈值配置化并附标定脚本，随嵌入模型更换重校 |
| RLS 层从代码中移除 | 应用层已做项目隔离（validate_project_access + FilterSpec），数据库层 RLS 维护成本高于收益，审计后删除死代码 |
| tools/list 按角色过滤 | 最小权限可见性：非本角色工具不出现在列表，避免 Agent 误调用与形态泄露 |
| 幂等键 (submitted_by, batch_type, operation_id) | 网络重试与客户端重放返回首次批次，落库持久化（跨重启）而非内存时间窗 |
| AGE MATCH 静默失败由应用层兜底 | Cypher MATCH 失败不报错，建边前显式校验端点节点存在，防止边静默丢失 |
