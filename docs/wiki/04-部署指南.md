# 部署指南

> 上一步：[工具手册](03-工具手册.md) · 下一步：[运维手册](05-运维手册.md)

部署操作细节（本地模型复用、故障排查、数据恢复）以仓库根目录 [DEPLOYMENT.md](../../DEPLOYMENT.md) 为准，本页给主路径与配置全景。

## 环境要求

| 项 | 要求 |
|----|------|
| 操作系统 | Linux（Ubuntu 22.04+ / CentOS 8+），Docker 24+ 及 Compose v2 |
| 内存 | 4GB 起，推荐 8GB+（Embedding 模型 CPU 推理约 2-3GB） |
| 磁盘 | 20GB 起，推荐 50GB+（含约 5GB 模型文件、镜像与 pg_data 卷） |

## 两步部署

```bash
cp .env.example .env
cd deploy
docker compose up -d --build
```

首次构建编译 AGE/pgvector/zhparser 扩展 + 下载 Embedding 模型，约 15-20 分钟。宿主机已有 Qwen3 模型时可叠加 `docker-compose.local.yml` 挂载复用（见 DEPLOYMENT.md §2.1）。

> v1.0.0 仅支持全新安装，不支持原地升级。旧部署如需保留数据，用 `deploy/backup.sh` / `restore.sh` 迁移，且旧数据须符合新契约（详见 DEPLOYMENT.md「更新版本」）。

## 创建首个 Admin Key

```bash
docker exec -it deploy-mem-lake-1 memlake-bootstrap-admin
```

明文 Key 只显示一次。admin 接入后用 `create_access_key` 为 PM/Dev 签发 Key——返回自带 `mcp_config` 与 Agent 接入提示词。

## MCP 客户端接入

```json
{
  "mcpServers": {
    "mem-lake": {
      "url": "http://<服务器IP>:8000/mcp",
      "headers": { "X-MCP-Key": "ak_xxx.xxx" }
    }
  }
}
```

接入后 Agent 调 `get_role_skills` 获取角色技能文档即可开始协作。

## 配置项总表（.env）

### 数据库

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | memlake | Compose 内拼装为 DATABASE_URL；生产改密码（仅首次初始化生效，改密需 ALTER USER） |
| `DATABASE_URL` | localhost 直连 | 非 Compose 本地开发场景才手改 |
| `DATABASE_POOL_SIZE` / `DATABASE_MAX_OVERFLOW` | 10 / 20 | 连接池，按并发调整 |

### MCP 网关

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `MCP_SERVER_NAME` / `MCP_SERVER_HOST` / `MCP_SERVER_PORT` | mem-lake / 0.0.0.0 / 8000 | 服务标识与监听 |
| `MCP_RATE_LIMIT_QPS` | 100 | 每 Access Key 令牌桶限流 |
| `MCP_PUBLIC_URL` | http://localhost:8000/mcp | 签发 Key 时写入 mcp_config 的地址，远程部署改公网/网关地址 |

### Embedding 与精排

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `TORCH_CUDA` | false | 构建期 torch 类型；true=cuda 镜像大需 GPU |
| `DOWNLOAD_MODEL` / `DOWNLOAD_RERANK_MODEL` | true / true | 构建期是否下载主模型/精排模型；false 配合 `docker-compose.local.yml` 挂载本地模型 |
| `EMBEDDING_DEVICE` | cpu | 推理设备 |
| `EMBEDDING_MODEL_PATH` / `EMBEDDING_DIMENSION` | ./models/Qwen3-Embedding-0.6B / 1024 | 模型与维度 |
| `EMBEDDING_HOST` / `EMBEDDING_PORT` | localhost / 8001 | Compose 内为 embedding 主机名 |
| `RERANK_MODEL_PATH` | 空（精排默认关闭） | 镜像内置 bge-reranker-base，填 `/models/bge-reranker-base` 启用精排；留空关闭 |
| `RERANK_TOP_K` / `ENABLE_RERANK` | 30 / true | 精排候选数与总开关 |

### 图、安全与治理

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `AGE_GRAPH_NAME` | mem_lake_graph | AGE 图名 |
| `BCRYPT_ROUNDS` | 12 | Key 哈希轮数 |
| `APPROVAL_WARNING_DAYS` / `APPROVAL_TIMEOUT_DAYS` | 7 / 30 | 审批超期标记 |
| `CONFLICT_SIMILARITY_THRESHOLD` | 0.85 | 冲突检测语义阈值；换模型后用标定脚本重校 |
| `LAX_MODE_ENABLED` | true | 宽松模式全局开关（false=强制审批熔断） |

### 可观测性

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `OBS_METRICS_ENABLED` | true | 挂载 /metrics（内网免鉴权，公网需防护） |
| `OBS_LOG_FORMAT` | console | console / json（生产推荐 json） |

## 端口与网络

| 容器 | 端口 | 对外建议 |
|------|------|----------|
| mem-lake | 8000 | 唯一对外放行 |
| postgres | 5432 | 生产移除映射或防火墙限制 |
| embedding | 8001 | 同上，仅容器网络内访问 |
